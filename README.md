# GSAP Learning Playground

A personal playground for learning and experimenting with GSAP animations using Vanilla JavaScript and Vite.

## 🚀 Tech Stack

- GSAP
- Vanilla JavaScript
- Vite
- HTML5
- CSS3

---

## 📚 What I'm Learning

This repository contains practice examples and mini demos for:

- GSAP Tweens
- `gsap.to()`
- `gsap.from()`
- `gsap.fromTo()`
- Easing
- Repeats & Yoyo
- Timelines
- Scroll Animations
- Advanced Motion Effects

---

```bash
 ├── styles/

````

## ⚡ Getting Started

### Clone the repository

```bash
git clone <your-repo-url>
```

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

---

## 🎯 Purpose

The goal of this project is to practice modern web animations and improve frontend animation skills using GSAP.
